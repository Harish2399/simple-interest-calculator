# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your change: `git checkout -b my-change`.
3. Make your changes and commit them with a clear message.
4. Push the branch to your fork and open a pull request.

## Reporting Bugs

Open an issue and include:

- A clear description of the problem
- Steps to reproduce it
- What you expected to happen and what actually happened

## Suggesting Enhancements

Open an issue describing the idea and why it would be useful.

## Code of Conduct

By participating, you agree to follow the project's [Code of Conduct](CODE_OF_CONDUCT.md).
